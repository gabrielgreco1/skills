# Brainstorm — when the user has no idea yet

Produce **10 ideas** in the user's language (Q0). Product: each one specific to the product and to something real on its
site (a feature, a stat, a ranking, a page). Story/topic: each one built on a verifiable, surprising fact. Mix the formats below so the list isn't 10 variations of one joke. For each idea give:

```
N. <Title> — <format>
   Story (one sentence a stranger could retell): ...
   Hook (first 3 s, states what's at stake): ...
   Product moment: <the real UI/data from the site that appears>   ·   Ends with: <what it solves + CTA>
```

Then ask the user to pick (SKILL.md → Q2). Allow multiple picks; each pick becomes one version.

## Formats that get shared (not ads)
| Format | Shape |
|---|---|
| Speedrun / game HUD | splits timer, any% category, the product is the "skip" |
| List meme | "things that cost $X": car, college, wedding… "one (1) <thing>" |
| Us vs them | big-company boardroom vs one person at 2 AM |
| Genre parody | horror / movie trailer where the monster is the real risk the product removes |
| POV / dev meme | over a git log, Slack thread, terminal — re-skinned in the brand |
| Street-interview supercut | chyrons + awkward-silence counter → the product answers (needs explicit context!) |
| Showreel | 15–20 s tour of the product's real UI components, motion-designer-portfolio energy |
| Data story | one ranking/stat revealed step by step, one item at a time |
| Teaser | 20 s, 3–4 beats, readable, made for outbound/sales sharing |
| Before/after | the painful manual workflow → the same task with the product |
| Countdown / leaderboard | top-5 reveal using the site's exact table/chart pattern |
| Explainer in 3 cards | problem → mechanism → result, big type |

## Story / topic formats (no product — curiosity content that people watch to the end)
See craft.md §1c for hooks and open loops:
| Format | Shape | Example |
|---|---|---|
| Then vs now (time race) | a real photo of the past → today, a counter/year ticker climbing, loop back to the first image | an archive photo of a city street → the same corner today |
| Infinite zoom | one continuous dive through scales with a real image at each level (object → part → microscope → atom) | "there are billions of these inside the thing in your hand" |
| How it's made | the impossible machine/process behind an everyday thing, each step a "wait, what?" | the factory step nobody imagines behind an everyday object |
| Hidden infrastructure | the invisible thing your everyday action depends on, with a local angle | "what happens in the two seconds after you tap pay" |
| Myth vs fact | a famous belief, then the surprising truth with a source | "everyone blames X — the real culprit is Y" |
| Scale comparison | an abstract number made physical (laps around the Earth, stadiums, fingernails) | "laid end to end, it would circle the Earth N times" |
| Origin story with an open loop | tease the payoff in the first 12 s, pay it off before the CTA | "the first version only lasted 3 weeks — I'll tell you why" |

## Filters before proposing
- Can a stranger get it in ~1 s from the title card? If it needs domain knowledge, the hook must supply it.
- Does it use something real from the site? (feature, stat, ranking, page copy)
- Does it end on what the product solves?
- Is it feasible with HTML motion + real photos (open banks) + Three.js 3D? (no live footage shot by us, no drawn humans)
- Story/topic: is every number verifiable from a citable source? Is there a local angle for the audience's country?
