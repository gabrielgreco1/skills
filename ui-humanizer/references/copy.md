# Copy que entrega IA na interface

Origem: @OnlyPedrinhu ("as provas sociais a copy meio porca"), @ViUmaVaga ("Visual e palavras específicas"), @vborotoo ("excesso de texto"), @junow0z (3 segundos pra saber o que a empresa faz). Casos: Capelon, Se Escute, Detran-RO.

Pra prosa longa (blog, sobre, artigos), use também a skill `humanizer`. Este arquivo cobre o texto curto de interface: headline, subtítulo, botões, cards, microcopy.

## Estruturas

| Estrutura | Exemplo | Troca |
|---|---|---|
| Headline abstrata de benefício | "Clareza para decidir melhor." "Transforme seu fluxo." | Diga o que é: "Escala de turnos pra restaurantes e clínicas" |
| "Chega de X" / "Diga adeus a X" | "Chega de perder horas com sua escala." | O que o produto faz, com número real se houver |
| Subtítulo que repete o headline | "O Capelon é a solução completa para a gestão de escalas." | Corte ou use pra informação nova (pra quem, preço, onde) |
| Tríade em frases curtas | "Mais automação. Mais controle. Menos trabalho." "Configure. Monte. Revise." | Uma frase com o fato mais importante |
| Pergunta retórica de seção | "Por que escolher a X?" "Por onde você quer começar?" "Pronto pra começar?" | Título que já é a resposta |
| Antes/depois genérico | "Como é hoje" vs. "Como deve ser" | Um caso real, ou corte |
| "Sem X" de fricção | "Sem complicação." "Sem fórmulas mágicas." "Sem cartão de crédito." | Diga o que tem, não o que falta |
| Lista de benefícios vagos com check | "Escalas prontas em menos tempo", "Toda a operação centralizada" | Fato verificável: "exporta pra PDF e manda no WhatsApp" |
| CTA genérico | "Comece agora", "Saiba mais", "Consulte aqui", "Ver como funciona", "Get started" | Verbo + objeto específico: "Montar a escala de março", "Ver o cardápio" |
| Prova social genérica | "+10.000 clientes satisfeitos", depoimento sem sobrenome/foto/empresa, logos "trusted by" de empresas que não são clientes | Só prova real, com nome e fonte vindos do usuário. Nunca invente |
| "Para todos" | Fileira de setores: "Restaurantes, Bares, Clínicas, Hospitais, Farmácias..." | Escolha o público principal e fale com ele |
| "Não é X. É Y." | "Não é mais um dashboard. É um centro de comando." "Não é uma ferramenta. É uma plataforma." | Diga o que faz numa frase direta; se a diferença importa, nomeie a alternativa e a diferença concreta |
| Marca com ponto no fim | logotipo ou wordmark terminando em ponto decorativo ("Acme.", "Linear.", "`<CYBER./>`") | Tire o ponto; ponto é de frase, não de nome de produto. É um tique de marca inventada por LLM |

## Palavras e expressões

Fracas sozinhas; em grupo, denunciam.

**PT:** solução completa, tudo em um só lugar, de forma simples, sem complicação, praticidade, eficiência, centralizado, potencialize, transforme, revolucione, simplifique, otimize, eleve, desbloqueie, inteligente(s) (em "Insights Inteligentes"), sua jornada, próximo nível, feito para você, pensado para, experiência única, de ponta a ponta, perfeito para.

**EN:** seamless, effortless, supercharge, unlock, elevate, empower, streamline, all-in-one, built for, designed for, next-level, game-changer, powered by AI, everything you need, in one place, get started, join thousands, trusted by, simple transparent pricing, revolutionize, cutting-edge, harness, in today's fast-paced world, built for the future.

## Formatação de texto na UI

- Título de seção em Title Case em PT ("Serviços E Consultas Públicas") é tell de tradução/IA. PT usa caixa de frase.
- Caixa alta só pra siglas e, se o design system pedir, rótulos muito curtos. Não em CTAs nem em eyebrows por default.
- Uma ideia por bloco. Se o card tem 3 linhas de descrição genérica, ele não precisa existir.
- Números concretos > adjetivos. "Abre às 6h" > "Sempre fresquinho pra você".

## Regra de ouro

Nunca invente fato pra deixar a copy "mais humana": cliente, número, depoimento, prêmio, tempo de mercado, nome de pessoa. Se falta, peça ao usuário ou deixe placeholder marcado.
